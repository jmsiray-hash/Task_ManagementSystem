# Tasks for Today Management System

An internal task management web application built using **CodeIgniter 4** and **MySQL** for IT0049 (Web System Technologies).

## 📌 System Pages & Features
1. **Welcome Page (`/`)**: Displays tasks scheduled for today.
2. **Task List (`/tasks`)**: Displays all tasks ordered by date.
3. **User Profile (`/profile`)**: Displays user profile information.
4. **About Page (`/about`)**: Information about the developer.
